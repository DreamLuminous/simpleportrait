# SimplePortrait 简照

一个面向个人用户的本地优先证件照制作工具。它把“选照片、调整构图、抠像换背景、导出文件”整理成一条清晰流程，也把照片压缩、抠像换背景和修改图片尺寸拆成职责单一的小工具。

> 当前版本：**v0.2.1 · Web/PWA 移动端适配修订版**

## 项目简介

做这个项目的出发点很简单：很多人只是临时需要一张符合尺寸、背景和文件大小要求的证件照，却要在多个工具之间反复换算、裁剪和压缩。SimplePortrait 简照希望把这些步骤放在一个容易理解的页面里，并尽量让照片留在用户自己的设备上完成处理。

首版优先完成 Web/PWA 体验，同时为微信小程序、iOS、Android、Windows、Linux 和 macOS 保留共享领域模型与平台适配边界。当前最适合使用的是桌面浏览器；移动端已经支持基础流程，但不同手机浏览器的相机、文件保存和触控行为仍会继续优化。

## v0.2.1 已完成

- 主页主操作提升文字与底色对比度，能力摘要改为规格自定义、双模式编辑和本地优先。
- 手机四步流程重做画布、参数区和底部导航分区，未上传照片时使用紧凑入口。
- 平板专业模式改为连续两栏工作台，输出参数不再覆盖中央画布。
- 证件照制作主流程：标准规格、上传/拍照入口、构图、背景、画面调整和导出。
- 普通模式：面向大多数用户的四步流程，详细参数按逻辑分组折叠，手机上更容易操作。
- 专业模式：单页深色工作台，规格、成像要求、画布、抠图、画面和输出同时可见。
- 普通模式与专业模式共享同一个制作会话，来回切换不丢失照片、构图、背景和导出设置。
- 四六级快捷设置：预填浅蓝色、192 × 144 PX、48 × 33 MM、10% / 70% / 20% / 10% 等推荐值，但所有具体参数仍可修改。
- 证件照模板库：一寸、小一寸、二寸、身份证、护照、考试报名、驾驶证、社保卡、方形照片和自定义规格。
- 成像要求可调整：头顶上空、头部区域、肩部区域、左右留空和眼睛参考线。
- 照片内鼠标拖动、鼠标滚轮缩放、照片外页面滚动；移动端单指拖动和双指缩放。
- 本地抠像：自动抠像、保留原背景、跳过处理、识别范围、边缘柔化、原图/结果对比、重新处理。
- 背景替换：白、蓝、红、浅蓝、自定义颜色、透明背景和浏览器原生取色器。
- 文件大小区间：当最大值小于最小值时自动修正，尽量保持用户设置意图。
- 文件名模板和普通文件名输入，不强制身份证号命名。
- 独立工具中心：照片压缩、抠像换背景、修改图片尺寸。
- 静态导出与 Netlify Drop 部署，生成目录为 `out/`。
- 首页使用说明、隐私提示、免责声明和中国大陆服务器部署准备说明。

## 功能边界

证件照中的“输出像素”和“成像区实体尺寸”是两个独立概念：改变其中一个不会自动移动或缩放人物构图。通用“修改图片尺寸”工具中的 PX、MM/CM 和 DPI 换算则只负责图片尺寸重采样，不负责目标文件大小。

照片压缩工具只改变文件体积，保持原始像素、比例和文件格式；无法达到目标区间时会提示用户，不会偷偷缩小像素或转换格式。透明背景只允许使用 PNG 导出。

自动抠像是本地浏览器能力，实际效果会受到头发、衣服、光线和背景反差影响。正式提交前请自行核对第三方机构的最新要求，模板不等于官方审核保证。

## 本地运行

环境要求：Node.js `>=22.13.0`。

```bash
npm install
npm run dev
```

开发服务默认地址：`http://localhost:5173/`

生产静态构建：

```bash
npm run build:netlify
```

构建完成后，静态文件位于 `out/`。可以把 `out` 文件夹中的内容直接拖到 Netlify Drop，或者将它作为普通静态站点目录部署到其他托管服务。

Netlify 已在 `netlify.toml` 中配置：

- 构建命令：`npm run build:netlify`
- 发布目录：`out`
- Node.js：22

## 开源项目结构

```text
app/
├── page.tsx                 # 首页、项目介绍、隐私和免责声明
├── id-photo/page.tsx        # 证件照制作页面
├── tools/page.tsx           # 独立工具中心
└── tools/
    ├── compress/            # 照片压缩
    ├── matting/             # 抠像换背景
    └── resize/              # 修改图片尺寸

lib/
├── photo-core.ts             # 单位换算、规格和归一化构图数据
└── ...                       # 图像及平台相关公共能力

components/                   # 通用界面组件
public/                       # 静态资源
tests/                        # 核心规则与浏览器交互检查
out/                          # 静态发布产物（构建后生成）
```

核心设计原则是：页面不直接绑定某个平台的相机、文件、权限和保存 API；证件照的规格、构图和导出规则保持在共享模型中，后续接入微信小程序或 App 时只替换平台适配层。

## 隐私与安全

- 普通裁剪、移动、缩放、调色、抠像和导出默认在当前设备浏览器中完成。
- 选择照片不会自动上传到简照服务器。
- 不要求注册账号，不把原图写入项目数据库，也不把照片作为训练数据。
- 托管平台仍可能按其安全策略记录必要的访问日志。
- 如果未来增加云端增强能力，应在单独提示后取得适用授权，并明确处理目的、保存期限和第三方服务。
- 请不要上传无权处理的照片，也不要将工具用于冒用身份、侵犯他人权益或其他违法用途。

完整说明见 [PRIVACY.md](PRIVACY.md)。备案编号与相关公示信息暂设为预留内容，取得真实信息后再补充。

## 项目经历记录

### 为什么做

这个项目从一个很具体的需求开始：希望给同学和身边的人提供一个打开网页就能用的证件照工具。证件照看起来只是裁剪一张照片，但实际涉及像素、毫米、DPI、成像比例、背景、文件格式和文件大小等多个容易混淆的条件。

### 我在第一版里解决的问题

1. 把采集图像大小、最终输出像素和成像区实体尺寸拆开，避免修改一个数值时意外改变另一个设置。
2. 用归一化坐标保存人物构图，使同一张照片在普通画布、专业画布、桌面和移动端之间保持一致。
3. 将普通模式和专业模式变成两套交互逻辑，而不是简单地把同一组控件收起或展开。
4. 把压缩、抠像换背景、修改图片尺寸拆成独立小工具，减少主流程中的干扰。
5. 把鼠标、触屏、双指缩放和画面外页面滚动区分开，处理桌面与手机的不同操作习惯。
6. 优先采用本地处理，减少个人照片上传和服务器存储带来的隐私风险。

### 第一版的真实限制

- 当前仍然以 Web/PWA 为主，微信小程序、原生 App 和桌面安装包还没有作为本版本的正式发布物。
- 自动抠像不是专业摄影软件级别，复杂发丝、半透明边缘和低反差背景仍需要人工检查。
- 不同浏览器对文件保存、相机权限和原生取色器的支持存在差异。
- 目前不包含账号、云同步、批量订单、服装替换、五官重塑和专业打印机色彩管理。
- 自定义规格只能给出质量建议，不会宣称一定通过某个机构的官方审核。

### 后续路线

- 抽取更完整的 `IdPhotoSession`、图像引擎和平台适配接口。
- 提升低内存设备上的大图处理、分块渲染和断点恢复能力。
- 完善微信小程序的相机、相册、文件保存和可选云端抠图授权流程。
- 封装 iOS、Android、Windows、Linux 和 macOS 构建链路。
- 增加版本化规格包、规格来源和适用地区提示。
- 继续优化无障碍、国际化、离线缓存和视觉快照测试。
