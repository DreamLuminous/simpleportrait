# SimplePortrait 简照 v0.2.0 发布说明

发布日期：2026-09-16  
发布形态：Web / PWA  
维护者：Luminous

## 版本定位

v0.2.0 是在首个公开版本基础上的第二阶段成果，完成了证件照主流程、普通与专业双模式、独立图片工具、移动端分步体验和公开合规页面的集中优化。当前版本仍处于 1.0 之前的持续改进阶段，不承诺第三方受理平台百分之百审核通过。

## 主要更新

### 证件照制作

- 普通模式采用四步流程，复杂参数按当前步骤分组展示。
- 专业模式采用独立深色工作台，在一个完整页面中显示规格、构图、画布、抠图、画面和输出设置。
- 普通模式与专业模式共享同一制作会话，切换模式不会清空照片和参数。
- 支持标准规格、四六级快捷设置、自定义像素、成像区毫米尺寸、DPI、构图比例、背景和文件格式。
- 采集像素与成像区尺寸可以联动，也可以保持独立。
- 分步编辑支持锁定和解锁照片工作区，避免完成构图后误操作。

### 构图与移动端

- 桌面端支持画面内鼠标拖动、以指针位置为中心的滚轮缩放和画面外页面滚动。
- 移动端支持照片内单指拖动与双指缩放。
- 移动端默认进入普通分步模式。
- 优化浏览器底栏、安全区域和横屏状态下的布局，减少下一步按钮被遮挡的问题。
- 修复数字输入框清空后重新输入仍带前导 0 的问题。

### 抠像与背景

- 证件照流程复用独立抠像工具的处理逻辑。
- 支持自动抠像、保留原背景、识别范围、边缘柔化、原图/结果对比和重新处理。
- 支持白色、浅蓝、蓝色、红色、自定义颜色和透明背景。
- 使用取色器时默认展示原图，便于采集原背景颜色。
- 透明背景限制为 PNG 导出。

### 输出与独立工具

- 文件大小区间支持自动纠正：最大值低于最小值时，优先将最小值调整为最大值减 5 KB；空间不足时与最大值保持一致。
- 压缩工具只调整文件体积，不改变像素、比例和格式。
- 抠像换背景作为独立工具提供。
- 修改图片尺寸独立负责 PX、MM、DPI、比例锁定和重采样。
- 支持 JPG、PNG、WebP 和 6 寸冲印排版输出。

### 品牌、开源与合规页面

- 全站品牌统一为 **SimplePortrait 简照**。
- 新增“关于我与联系”模块，集中展示维护者、邮箱和开源仓库。
- 联系邮箱：Dreamluminous@163.com。
- 开源仓库：https://gitee.com/luminousone/simpleportrait
- 新增正式隐私政策与使用条款页面。
- 备案编号区域仅保留展示位置，取得真实信息后再补充。

## 当前限制

- 自动抠像为浏览器端轻量实现，复杂发丝、透明物体和相近背景可能需要重新处理或保留原背景。
- 不提供政府、学校、考试机构或其他受理单位的审核保证。
- 当前正式发布物只有 Web / PWA；微信小程序、iOS、Android、Windows、Linux 和 macOS 仍属于后续移植规划。
- 不包含账号、云同步、支付、批量订单、服装替换和五官重塑。
