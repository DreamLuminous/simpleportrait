# SimplePortrait 简照 v0.2.2 发布说明

发布日期：2026-09-17  
发布形态：Web / PWA  
维护者：Luminous

## 版本定位

v0.2.2 是面向真实手机、平板和电脑使用场景的设备分层适配修订版。本版不新增账号、云同步或在线照片存储，而是集中处理多模式、多步骤和不同屏幕方向叠加后产生的布局冲突，使证件照主流程在小屏、平板和桌面端分别采用更明确的交互结构。

当前版本仍处于 1.0 之前的持续改进阶段。证件照模板、构图提示和文件大小调整只提供制作辅助，不代表政府、学校、考试机构或其他第三方平台一定审核通过。

## 主要更新

### 手机端

- 手机端强制使用普通分步骤制作，不再显示专业模式入口。
- 手机横屏仍按手机流程处理，避免旋转后意外进入桌面或平板专业布局。
- 保留照片锁定与解锁、单指拖动、双指缩放、拍照、上传和本地导出。
- 底部步骤导航继续适配全面屏安全区域与移动浏览器工具栏。
- 模式锁定不会覆盖电脑端已经保存的专业模式偏好。

### 平板竖屏

- 建立独立的平板竖屏分步骤布局，不再直接复用手机或电脑页面。
- 画布、参数区域和底部导航使用独立网格行，减少显示不全与互相覆盖。
- 第一步规格列表、第二步构图、第三步抠图与背景、第四步导出分别使用适合竖屏空间的高度分配。
- 设置区域可以独立滚动，底部导航保持在可操作范围内。

### 平板横屏

- 普通模式使用左侧画布、右侧当前步骤参数的双栏布局。
- 平板横屏可以启用专业模式。
- 专业模式使用规格与画布双栏，完整调整和输出参数在下方连续排列。
- 取消容易覆盖画布的粘性参数面板，修复文件大小、背景和导出控件横跨工作区的问题。

### 电脑大屏

- 保留普通模式双栏与专业模式完整三栏工作台。
- 增加面板最小宽度、横向溢出和长内容约束。
- 改进文件大小区间、文件名、导出摘要、按钮和页脚在边界尺寸下的显示。

### 分步骤流程

- 第三步统一命名为“抠图与背景”。
- 第三步始终保留完整照片画布；未上传照片时不再折叠成狭窄上传条。
- 第四步取消重复照片预览，改为纯检查与导出页面。
- 第四步为文件格式、质量、文件大小区间、文件名、导出摘要、电子照保存和冲印版提供完整空间。

## 当前限制

- 自动抠像仍是浏览器端轻量实现，复杂发丝、半透明物体、阴影和主体与背景颜色接近时可能需要重新处理或保留原背景。
- 不提供政府、学校、考试机构或其他第三方受理平台的审核保证。
- 当前正式发布物仍为 Web / PWA；微信小程序、iOS、Android、Windows、Linux 和 macOS 属于后续移植规划。
- 不包含账号、云同步、支付、批量订单、服装替换和五官重塑。
