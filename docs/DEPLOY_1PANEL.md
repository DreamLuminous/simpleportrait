# 1Panel 静态网站部署说明

对应版本：SimplePortrait 简照 v0.2.2

## 使用范围

本包是已经构建完成的静态网站，不需要在服务器上安装 Node.js、运行 npm，也不需要配置图片处理后端。

## 部署步骤

1. 在 1Panel 中创建一个静态网站，并绑定准备使用的域名。
2. 为网站启用 HTTPS。
3. 打开阶段成果目录中的 `1Panel服务器/网站根目录`。
4. 将“网站根目录”里面的全部文件上传或复制到 1Panel 为该网站创建的网站根目录。
5. 确认服务器网站根目录直接包含 `index.html`，不要多套一层“网站根目录”文件夹。
6. 使用浏览器访问首页，并检查 `/id-photo/`、`/privacy/`、`/tools/`。
7. 如果直接访问子页面返回 404，可参考同目录的 Nginx 配置片段增加静态路由查找规则。

## 更新方式

后续发布新版本时，先备份服务器上的旧网站目录，再用新版本“网站根目录”中的文件覆盖。HTML 和普通静态资源可以覆盖；不要把服务器证书、站点日志或 1Panel 自己生成的配置文件复制回项目目录。

## 安全与备案

- 不要把原始照片、测试照片、环境变量、日志或备份压缩包放入公开网站目录。
- 当前网站只预留备案信息显示位置；取得真实备案信息后再更新页面。
- 域名、HTTPS、访问日志、备案和服务器安全策略应按实际部署情况配置。
