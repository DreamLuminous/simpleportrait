# SimplePortrait 简照 v0.2.1 发布说明

发布日期：2026-09-17  
发布形态：Web / PWA  
维护者：Luminous

## 版本定位

v0.2.1 是 v0.2.0 之后的体验修订版本，重点处理真实手机和平板访问时暴露的布局问题，同时提升主页主要入口的可读性。本版不改变证件照核心数据模型，也不会在普通模式和专业模式切换时清空当前工程。

## 主要更新

### 主页

- 提升“开始制作证件照”按钮的背景和文字对比度，补充悬停与键盘焦点状态。
- 将“默认采集像素”和单一毫米尺寸改为总体能力说明：规格可自定义、普通/专业双模式和本地优先。
- 保留 SimplePortrait 英文主品牌与中文“简照”名称。

### 手机普通模式

- 顶部导航改为双层紧凑布局，避免品牌、语言、模式和设置按钮互相挤压。
- 第 2 步的画布、构图提示和底部导航改为独立区域，不再相互覆盖。
- 第 3、4 步使用上方紧凑预览、下方参数区和独立底部导航。
- 未上传照片时使用横向紧凑上传入口，不再显示占据大半屏幕的空白画布。
- 底部导航适配全面屏安全区域和移动浏览器工具栏。

### 平板与专业模式

- 761—1280px 范围使用平板专用专业工作台。
- 规格设置与专业画布位于上方两栏，完整调整和输出参数位于下方连续区域。
- 修复文件大小、背景与输出控件跨列覆盖照片画布的问题。
- 手机专业模式保持连续纵向页面，横屏状态使用更紧凑的画布尺寸。

## 当前限制

- 自动抠像仍为浏览器端轻量实现，复杂发丝、半透明物体和相近背景可能需要重新处理或保留原背景。
- 模板和质量检查只提供制作辅助，不代表政府、学校、考试机构或其他第三方平台一定审核通过。
- 当前正式发布物仍为 Web / PWA；微信小程序、iOS、Android、Windows、Linux 和 macOS 属于后续移植规划。
- 不包含账号、云同步、支付、批量订单、服装替换和五官重塑。

## 验证结果

v0.2.1 发布目录生成前已完成：

- 核心尺寸换算、构图与输出规则测试。
- 普通/专业模式、抠图、鼠标和触控交互回归测试。
- 390 × 844 手机空状态四步流程专项检查。
- 768 × 1024 平板竖屏与 1024 × 768 平板横屏专业模式检查。
- 静态生产构建和主要页面文件检查。
