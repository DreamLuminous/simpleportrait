# SimplePortrait 简照 v0.2.3 发布说明

发布日期：2026-09-18  
发布形态：Web / PWA 源码与 1Panel 静态部署包  
维护者：Luminous

## 版本定位

v0.2.3 是 v0.2.2 设备分层适配之后的安全、导出与响应式精修版。本发布资料已合并 v0.2.3 首次整理和后续手机/平板精细适配，作为同一个版本、同一次 GitHub Desktop 提交和同一个 1Panel 部署包发布。本版继续以浏览器本地处理为主，集中修复分步导出按钮、文件大小区间、KB/MB 单位、大图上传保护、画布尺寸上限以及手机、平板和电脑端的工作区利用率。

本版不增加账号、云端照片存储、支付或第三方审核承诺。模板和输出参数仍需由用户按照实际受理机构要求核对。

## 主要更新

### 分步制作与多端布局

- 恢复普通分步模式第 4 步“保存电子证件照”按钮。
- 第 3 步抠图和第 4 步导出均保留照片画布，调整背景、画质和输出参数时可以直接查看结果。
- 电脑普通模式把当前步骤的详细设置放入右侧，提高横向空间利用率。
- 手机及大屏手机锁定为普通四步流程，不再渲染专业模式入口；平板竖屏、平板横屏和电脑分别使用独立布局规则。
- 手机第 2、3、4 步使用相同的动态画布高度，第三步直接进入抠图，第四步直接进入导出设置。
- 照片锁定/解锁按钮移到画布外部工具栏，避免覆盖照片和构图参考线。
- 修复 701—760 px 小平板顶部栏误用手机规则导致的重叠。
- 竖屏平板重新分配构图画布与控制区比例；专业模式保持连续深色工作台并动态限制画布高度，减少空白、重叠和面板越界。

### 文件大小区间

- 证件照和独立照片压缩工具支持 KB / MB 单位切换。
- MB 模式支持小数输入，界面最多显示三位小数，输入步进为 0.01 MB。
- 内部统一以 KB 计算，切换单位不会改变目标值。
- 最小值和最大值使用双向约束，无论先填写哪一侧都保证“最小值 < 最大值”。
- 目标区间最高为 20 MB，异常大值会被限制，不会进入编码过程。

### 上传与内存安全

- JPEG、PNG、WebP 单张上传最大 30 MB。
- 上传图像最长边最大 12000 px，总像素最大 3000 万。
- 超出限制时停止载入、抠图或压缩，并显示明确原因。
- 证件照输出尺寸限制为 64—6000 px，成像区限制为 5—500 mm，DPI 限制为 72—600。
- 尺寸工具输出最长边限制为 6000 px、总像素限制为 3000 万；大图初始输出按比例缩小。

### 相机、抠图与输出

- 新增浏览器相机授权弹窗和实时预览，只有用户点击拍照时才申请权限。
- HTTP 环境不能调用摄像头时明确提示使用 HTTPS 或改用文件上传。
- 独立抠图工具移除重复的处理模式开关，上传后直接自动抠图，仍保留原图对比、取色器和透明背景。
- 明确“6 寸”为相纸尺寸，排版数量根据当前证件照实体尺寸自动计算。

## 发布与在线版本状态

- 本轮生成 v0.2.3 的 1Panel/OpenResty 静态部署包。
- 本轮不生成 Netlify 上传包，Netlify 暂停更新。
- GitHub 仓库源码可以更新到 v0.2.3，但 GitHub 项目网页/在线预览暂时冻结在 v0.2.2。
- 因此仓库源码版本与在线预览版本可能不同，请以页面标注和本文件为准。

## 当前限制

- 自动抠图是浏览器端轻量实现，复杂发丝、透明物体、阴影和相近背景仍可能需要调节或保留原背景。
- 小像素证件照通常无法编码到很大的 MB 下限；无法达到目标区间时会提示，不会填充无意义数据。
- 浏览器相机通常要求 HTTPS；公共 IP 的普通 HTTP 页面即使已经部署，也可能被浏览器阻止访问摄像头。
- 当前正式发布物仍是 Web / PWA，微信小程序、原生移动端和桌面端属于后续规划。

## 验证结果

发布目录生成前已完成：

- 核心尺寸换算、命名和排版测试。
- KB/MB 切换、MB 小数、20 MB 上限和区间双向修正测试。
- 390 × 844 手机、744 × 1133 与 834 × 1112 竖屏平板、1112 × 834 横屏平板和 1440 × 900 电脑浏览器交互回归。
- 手机第 2—4 步画布等高、手机专业模式隐藏、锁定按钮外置和小平板顶部栏无重叠检查。
- 鼠标拖动、滚轮缩放、单指拖动、双指缩放和画布锁定检查。
- 静态生产构建及 1Panel 网站根目录检查。
